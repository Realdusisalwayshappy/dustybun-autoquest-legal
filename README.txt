DUSTYBUN X AUTOQUEST 24HR — LEGAL PAGES

Files:
- index.html: landing page
- terms.html: Terms of Service
- privacy.html: Privacy Policy

Publish with GitHub Pages:
1. Create a public GitHub repository, for example: dustybun-autoquest-legal
2. Upload all three HTML files to the repository root.
3. Open the repository's Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. Wait for GitHub Pages to publish the site.

Your URLs will follow this pattern:
https://YOUR-GITHUB-USERNAME.github.io/dustybun-autoquest-legal/terms.html
https://YOUR-GITHUB-USERNAME.github.io/dustybun-autoquest-legal/privacy.html

Replace YOUR-GITHUB-USERNAME and the repository name with your actual values.
Then paste the two published URLs into the Discord Developer Portal's Terms of Service URL
and Privacy Policy URL fields.
